# Code of Conduct

Lantern Wishes welcomes respectful participation from people with different backgrounds and levels of experience. Keep discussions constructive and focused on the project.

Unacceptable behavior includes harassment, discriminatory language, personal attacks, deliberate disruption, and sharing another person's private information without permission.

Project maintainers may edit or remove unacceptable contributions and may restrict participation when needed to keep the project welcoming. Report conduct concerns privately to the maintainers through GitHub rather than posting personal details in a public issue.

This code of conduct applies in project issues, pull requests, and other spaces used for project work.
